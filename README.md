## 先按用量习惯选，而不是按名气选

* **偶尔查资料、用量很小**：优先找一次买断、流量永久有效的类型，避免月付到期清零。
* **经常刷视频、多设备同时在线**：先比较各档位折算下来的每 GB 单价，再实测晚高峰速度。
* **在意延迟和稳定性**：优先选带专线的套餐，通常比普通中转贵，但高峰期差距很明显。
