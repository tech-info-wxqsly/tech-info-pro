## 常见问题

### 科学上网、翻墙、机场、VPN，这几个词是一回事吗？

日常语境里经常混着用，但技术上并不相同：

* **VPN** 原本是企业把办公设备接入内网的技术，协议设计目标并不是绕过网络限制；市面上叫"VPN 软件"的产品，多数只是借用了这个词。
* **机场** 是中文圈对代理订阅服务的通俗叫法，普遍基于 Vless、Hysteria2、AnyTLS 这类协议，用一条订阅链接把节点批量导入客户端。
* **科学上网**和**翻墙**是同一类需求的两种说法，本质都是让设备能访问原本访问不了的境外站点。

所以本文推荐的是"机场"这类订阅服务，客户端则是 Shadowrocket、Clash Verge、FlClash 这几个。

### 流量不清零和月付大流量，到底怎么选？

看自己的用量曲线：每月只偶尔查资料、看几篇文章的，选一次买断、流量永久有效的类型，用多少扣多少，不会因为到期清零而浪费；每天刷视频、下文件或几个人共用的，选月付大流量，单位价格更低，但要留意续费与流量重置规则。拿不准就先买最小档跑几天晚高峰。

### 机场和自建节点有什么区别？

自建要自己买服务器、维护协议与证书、处理 IP 被封锁后的迁移，适合愿意折腾的人；机场把线路维护和节点更新都包了，省事但依赖服务商质量。日常使用主流是机场，自建更适合当备用。

### 导入订阅后连不上，先检查什么？

按顺序排查：先在客户端点一次更新订阅（节点列表几乎每天都在变）；再确认设备时间是否准确，时间偏差会导致 TLS 握手失败；然后看当前网络是否限制了 UDP；最后把模式从"规则"切到"全局"试一次，全局能用就说明是分流规则没覆盖。

### 同一份订阅能在手机和电脑上同时用吗？

多数机场按流量计费、不限制设备数，一份订阅可以同时导入手机、电脑和平板；少数套餐会限制同时在线设备数，购买前看套餐说明里的"设备限制"那一栏。
