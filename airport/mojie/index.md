这是我长期留着的备用线。 一次买断、流量永久有效，用多少扣多少，不存在到期作废——代价是折算单价高于月付大流量套餐，所以它适合当第二条线，不适合当每天都在下载的主力。

## 计费方式：买断制到底省在哪

魔戒走的是**一次性买断**模型：付一次钱拿到一个流量池，没有到期日，剩余流量不会因为「这个月没怎么用」而清零。

对用量忽多忽少的人，这一点比单价更重要。月付大流量套餐看着便宜，但「额度按月重置」意味着用不完的部分直接作废；买断制则把没用完的流量留到你需要它的那个月。

## 谁该买，谁不该买

| 场景 | 建议 |
| --- | --- |
| 每周只查几次资料，月用量 5G 以内 | 直接买 130G 或 210G，够用很久，不用担心清零 |
| 已经有主力线路，想加一条备用 | 最合适的用法。主力波动、维护、临时封锁时，切过去只要几秒 |
| 每天都在看 4K 或下载大文件 | 不适合。折算单价明显高于月付大流量，这类用量应该去 [KTM](../ktm/index.html) 那类大流量套餐 |
| 几个人共用一条线 | 不太适合。买断流量池是共享消耗，多人一起用会消耗得很快 |

## 两个入口的区别

页面上给的两个入口是**同一家的不同线路入口**，不是两家服务商。其中一个打不开时换另一个试——这在临时封锁或单个入口被干扰时很有用，也是它适合当备用线的原因之一。

## 下单前要确认的三件事

1. **先买最小档验证本地网络。** ¥1 的 1G 档足够跑一次晚高峰测速。线路体验受本地运营商和地区影响很大，别人快不代表你快。
2. **确认当前单价。** 站内表格是从官方套餐页抄下来的，机场调价很频繁，以官方价目页为准。
3. **确认协议兼容性。** 魔戒提供 Vless / Hysteria2 / AnyTLS 三种协议，常见客户端都支持；如果你用的是 Windows 上的 Clash Verge，导入步骤见 [Clash Verge 订阅导入与分流教程](../../guides/clash-verge-subscribe.html)。

## 和其他线路怎么搭配

最稳的做法是**一条主力 + 一条备用**：主力按你的用量模型选，备用选便宜的买断小套餐。魔戒在这里扮演的是备用那一半。
