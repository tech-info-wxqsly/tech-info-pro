iPhone 代理客户端配置：电脑临时桥接与后续选择

只想应急，直接走路线一；想长期在手机上用，走路线二。两条路线可以按顺序来，也可以只挑需要的那条。

路线一是过渡方案：手机不装任何软件，借用电脑的网络出口，适合临时使用。
路线二是长期方案：在 App Store 选择所在地区当前可用的原生客户端，并按 Apple 现行账号与商店规则安装，之后手机可独立使用。

一、路线一：让电脑做跳板（手机端零安装）

做法本身不复杂：电脑上的代理客户端打开「允许局域网连接」之后，会在本机开放一个代理端口（常见是 7890）。把手机和电脑接在同一个 WiFi 下，再让手机的 WiFi 走手动代理指向电脑的内网地址，手机的流量就从电脑那边出去了。

第一步：打开客户端的局域网共享开关

Clash Verge、FlClash、Mihomo 这一类客户端，设置里都有一个 允许局域网连接（Allow LAN） 的开关，打开它。同时留意「混合端口 / Mixed Port」的数值，默认多为 7890，下面手机上要填的就是这个端口。

第二步：查出电脑在局域网里的地址

  • Windows：按 Win + R，输入 cmd 回车，执行 ipconfig，在无线网卡那一段找到 IPv4 地址，形如 192.168.1.23。
  • Mac：系统设置 → 网络 → 选中当前 WiFi → 详细信息，里面能看到 IP 地址。

第三步：在手机的 WiFi 设置里填代理

  1. iPhone 打开「设置 → 无线局域网」，点当前 WiFi 右侧的 ⓘ 图标。
  2. 滑到最底部找到「配置代理」，切换成手动。
  3. 服务器一栏填电脑的内网地址，端口填刚才记下的那个端口，保存。
  4. 使用你有权访问的测试网站或服务，检查代理配置是否按预期工作。

连不上时的排查顺序

先确认手机和电脑在同一个网段（IP 前三段一致）；再检查 Windows 防火墙有没有拦掉这个端口的入站连接；如果是在酒店、商场或公司 WiFi 下，这类网络经常开了 AP 隔离，设备之间互相看不见——优先改用可信的家庭网络测试；公共网络不适合开放代理端口。

安全收尾：开启「允许局域网连接」会让同一局域网内的设备尝试连接电脑代理。仅在可信网络下短时开启，用完后关闭 Allow LAN，并在 iPhone 的「配置代理」里恢复为「关闭」或原来的设置；不要在公共 WiFi 中长期开放，也不要为此关闭系统防火墙。

二、路线二：安装原生客户端（以 App Store 当前可用性为准）

想长期在手机上使用，可以查看自己所在地区的 App Store 当前提供哪些客户端。应用上架情况与账号地区规则可能变化；如需切换「媒体与购买项目」账号，请遵循 Apple 当前要求，并使用自己可控的账号。不要把他人共享账号登录到 iCloud。

第一步：核对账号地区与商店要求

如需切换账号地区或新建账号，先核对 Apple 当前的账号创建、地区与付款要求，只填写真实、准确且本人可使用的信息；不要使用虚构或他人的账单资料。流程与选项可能变化，详见Apple 账号地区与购买项目注意事项。

第二步：按 Apple 流程登录并下载

  1. 如需切换媒体与购买项目账号，按 Apple 官方当前步骤操作，并只登录自己可控且符合账号地区规则的账号。
  2. 打开 App Store 搜索并安装你选定的客户端（下一节有对比）。
  3. 装完可以切回自己的常用账号，已装的 App 不会被删除，但以后更新时要重新登录美区账号。

四、桌面端和安卓端用什么

  • Windows：Clash Verge Rev、FlClash、Mihomo Party，都支持订阅导入与规则分流。
  • macOS：Clash Verge Rev、Stash，或者付费的 Surge。
  • Android：FlClash、Clash Meta for Android、v2rayNG。

桌面端和手机端用的是同一份订阅链接，导入方式各家略有差别，基本都在「订阅 / Profile」页面里粘贴。

五、几个高频问题

订阅导进去了，但节点一个都测不通？

先在客户端里点一次「更新订阅」，多数商家的节点列表每天都会变。还不行就检查设备时间是否准确——时间偏差过大会直接导致 TLS 握手失败，这一条经常被忽略。

代理明明连上了，个别 App 还是打不开？

大概率是分流规则没有覆盖到。把模式从「规则」临时切成「全局」验证：全局能用、规则不能用，就是规则集的问题，更新规则或手动补一条即可。

电脑关机之后手机还能用吗？

路线一不行，那种方式本来就是借电脑的网络。走完路线二、手机上装好原生客户端之后，就可以脱离电脑独立使用了。

为什么要先买最小档的套餐？

线路体验和本地运营商、所在地区、使用时段关系很大，别人说快不代表你这边快。先用小额套餐跑几天晚高峰，再决定要不要续长期，这样最省钱。

六、使用须知

  • 请遵守所在地的法律法规以及相关服务条款，把工具用在正当的信息获取用途上。
  • 不要从第三方渠道购买来历不明的账号或订阅，存在账号被收回和信息泄露的风险。
  • 线路都可能出现波动，建议至少保留一条备用线路，并定期更新订阅与客户端版本。
  • 本文只讲操作方法与排查思路，不构成对任何具体服务的推荐或担保。
