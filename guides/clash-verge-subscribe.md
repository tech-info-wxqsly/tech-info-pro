# Clash Verge 订阅导入教程：从安装到分流规则

一句话结论：**订阅导入有三种方式，最省事的是复制订阅链接后在客户端里选「从剪贴板导入」**。导入成功只是第一步，能不能用得舒服，取决于你后面选了什么代理模式和规则。

## 开始之前

需要准备两样东西：

1. 一条可用的订阅链接（机场后台「一键订阅」或「复制订阅链接」处获取，通常是一串 `https://` 开头的地址）。
2. 客户端本体。Clash Verge 的活跃维护版本叫 **Clash Verge Rev**，内核用的是 Mihomo（原 Clash Meta），下载请认准官方仓库的 Release 页面，别用来路不明的"绿色版"，这类客户端会读取你的全部流量配置。

## 一、下载与安装

| 平台 | 下载文件 | 说明 |
| --- | --- | --- |
| Windows | `*_x64-setup.exe` 或便携版 | 安装后首次启动可能提示安装服务，用于开启 TUN 模式 |
| macOS | `*.dmg`，注意区分 Intel 与 Apple 芯片 | 首次打开若被 Gatekeeper 拦截，到「系统设置 → 隐私与安全性」放行 |

安装完先别急着导入订阅，打开设置确认两件事：**混合端口**（默认 7890）和**语言**。端口号后面排查问题时要用到。

## 二、导入订阅的三种方式

### 方式一：从剪贴板导入（推荐）

在机场后台点「复制订阅链接」，回到 Clash Verge，进入 **订阅** 页面，点击「新建 / 导入」，选择**从剪贴板导入**。客户端会自动识别剪贴板里的链接并拉取配置，成功后会出现在订阅列表里。

这个方式最不容易出错，因为它不需要你手工拼接参数。

### 方式二：直接填订阅链接

如果剪贴板导入没反应，就手动新建一个订阅，把链接粘贴到 URL 一栏。注意两点：

* 链接必须是**订阅地址**，不是机场官网的其他页面地址。
* 有些机场要求指定客户端类型，需要在链接后追加参数，例如 `&flag=clash`，具体看机场说明文档。

### 方式三：导入本地配置文件

部分机场提供「下载 Clash 配置文件」，会得到一个 `.yaml` 文件。这种就用「从本地文件导入」。好处是配置里可能已经带好了分流规则，坏处是节点更新需要重新下载文件，不能自动更新。

## 三、导入之后先测速，别急着用

订阅导入成功后，进入 **代理** 页面，点一次「测速 / 延迟测试」。这一步的价值是：

* 把明显超时或延迟上千毫秒的节点先排除掉；
* 观察同一地区节点之间的差异，晚高峰尤其明显；
* 记住两三个延迟最低、且连续几天都稳定的节点，作为主力。

延迟数字只是参考，**能打开网页、看视频不转圈，才算真的好用**。有些节点延迟很低但丢包严重，实际体验反而更差。

## 四、代理模式：规则、全局、直连

| 模式 | 行为 | 什么时候用 |
| --- | --- | --- |
| 规则（Rule） | 按规则集分流，境外走代理、国内直连 | 日常默认，最推荐 |
| 全局（Global） | 所有流量走代理 | 排查问题时临时用，正常使用会拖慢国内网站 |
| 直连（Direct） | 全部直连，不走代理 | 需要临时关代理时 |

排查思路很简单：**某个网站打不开时，把模式切到全局再试一次**。全局能打开、规则打不开，说明是分流规则没覆盖到这个域名，更新规则集或手动加一条规则即可；全局也打不开，问题在节点或订阅本身。

## 五、TUN 模式什么时候需要

普通模式（系统代理）只对遵守系统代理设置的程序生效，一些不走系统代理的软件——比如部分游戏、某些客户端、命令行工具——就会漏出去。**TUN 模式**创建虚拟网卡接管全部流量，可以覆盖这些程序。

代价是权限更高、配置更复杂：Windows 需要安装服务组件，macOS 需要授权网络扩展。如果你的需求只是浏览器和常见应用，先用普通模式即可；发现某些软件不生效再开 TUN。

## 六、保持订阅最新

机场的节点列表几乎每天都会变。在订阅设置里把**自动更新间隔**设为 24 小时，日常就基本不用管；遇到某个节点突然不可用，先手动点一次更新再说，很多时候不是节点坏了，而是它已经被换掉了。

## 七、导入后完全没反应，按这个顺序排查

1. **先看订阅有没有真的拉下来**：订阅列表里显示流量、到期时间才算成功，只有名字没有数据，通常是链接不对或已过期。
2. **检查设备时间**：系统时间偏差过大会直接导致 TLS 握手失败，这一步最容易被忽略。
3. **换网络再试一次**：部分网络会对订阅域名做拦截，换成手机热点往往能拉下来。
4. **确认端口没被占用**：7890 被其他软件占用时，客户端会启动失败，改一个端口即可。
5. **看日志**：Clash Verge 的日志页面会直接写明错误原因，比反复点按钮有效得多。
