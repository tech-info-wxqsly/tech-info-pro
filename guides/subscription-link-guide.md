# 机场订阅链接：怎么获取、怎么备份、泄露了怎么办

一句话结论：**订阅链接等于你的账号密码，不要发到任何公开场合。** 它一旦泄露，别人可以用你的流量，而你只能通过重置订阅地址来止损。

## 一、订阅链接在哪里

登录机场后台后，通常在「我的订阅」「一键订阅」「仪表盘」这类位置，会看到一行 `https://` 开头的长地址。它和我们平时看到的官网地址不是一回事：

| 地址类型 | 特征 | 能不能用来导入 |
| --- | --- | --- |
| 官网首页 | 短、好记 | 不能 |
| 登录后的面板地址 | 带 `/#/` 或 `/#/dashboard` | 不能 |
| **订阅地址** | 路径里带 `token=` 之类的长串，粘贴后客户端直接拉配置 | 能 |

很多新手反复导入失败，原因就是在后台复制了面板地址。

## 二、为什么说它等于账号密码

订阅链接里通常内嵌了一个长期有效的 token。拿到这条链接的人可以做三件事：

1. 用你的流量、共你的带宽；
2. 看到你的订阅里有哪些节点、剩余多少流量；
3. 在某些实现不严谨的机场里，进一步关联到账号信息。

所以下面这些做法都要避免：

* 把订阅链接发到群里"求帮看为什么连不上"；
* 粘贴到公开论坛、贴吧、GitHub issue 里截图；
* 用在线"订阅转换"网站时不做任何防护——转换服务能看到你的完整链接。

## 三、泄露了怎么处理

到机场后台找「重置订阅地址」或「重新生成订阅」的按钮，点一次，旧的订阅链接立即失效。

重置之后你需要**在所有设备上重新导入一遍**：客户端里删掉旧订阅，再用新链接添加。这一步别偷懒用"编辑订阅地址"，有些客户端会缓存旧配置，直接删掉重建更干净。

## 四、订阅链接怎么备份

推荐的做法是：**存一条、记两条、画一条**。

* **存一条**：把订阅地址存进密码管理器（Bitwarden、1Password 之类）。它本质上是凭据，就该放在存凭据的地方。
* **记两条**：记下到期日期，以及购买时用的账号邮箱。到期前一周你需要在邮箱里找续费信息。
* **画一条**：重置订阅地址前后，把新旧链接的切换时间记一下，方便排查"为什么突然不能用了"。

不建议把订阅链接直接写在备忘录 App 的普通笔记里，也不要截图后放在相册——这两处的同步与分享范围往往比你以为的大。

## 五、订阅的日常检查清单

每隔一两周花一分钟看一遍后台：

| 检查项 | 为什么 |
| --- | --- |
| 剩余流量 | 快用完时提前续费，避免突然断线 |
| 到期时间 | 提前处理，避免到期当天手忙脚乱 |
| 是否有新节点 | 服务商会不定期加线路，可能有更适合你的 |
| 公告 | 维护、迁移、换域名的通知都发在这里 |

如果后台访问不了、但设备上的节点还能用，通常只是面板域名被拦，不影响使用；这时先用现有订阅顶着，等服务商换域名即可。

## 附：导入时可能要追加参数

同一个机场往往给不同客户端准备不同的配置格式，有些链接需要手动追加参数，例如：

```
&flag=clash      # 让服务端返回 Clash 格式
&flag=shadowrocket
```

具体叫什么名字，看机场自己的说明文档。多数情况下，用客户端里的「从剪贴板导入」会自动带上正确参数，这也是推荐这种导入方式的原因；正常拿到链接后直接导入即可，遇到问题再回来对照这一节。

拿到链接后的导入步骤，见 [Clash Verge 订阅导入与分流教程](clash-verge-subscribe.html)；手机上对应的操作见[小火箭订阅导入失败排查](shadowrocket-subscribe-troubleshooting.html)。
