# 美区 Apple ID 注册避坑：从零到装上 iOS 客户端

一句话结论：**注册一个属于自己的美区账号，只把它登录在 App Store 的「媒体与购买项目」里，绝不要登进 iCloud。** 这是既省事又安全的分界线。

## 为什么建议自己注册，而不是买共享账号

共享账号的问题不在价格，而在风险不对称：

* 卖家随时可以改密码或收回账号，你装好的 App 之后更新不了；
* 同一账号被多人在多地登录，容易触发风控被锁；
* **最危险的是把共享账号登进 iCloud**——那样对方可以访问照片、通讯录，甚至远程锁定或抹除设备。

自己注册一个账号，成本只是一个邮箱和十分钟，之后长期可用。

## 准备三样东西

| 准备项 | 建议 |
| --- | --- |
| 邮箱 | 单独准备一个，不要用主力设备绑定的主账号邮箱，常见域名邮箱都能收到验证码 |
| 地址 | 建议填免税州，例如 Oregon、Delaware、Montana |
| 网络 | 注册过程偶尔需要稳定的境外网络环境，能正常打开苹果页面即可 |

地址的填写要点是**州、城市、邮编要在同一区域**。比如选了 Oregon，城市填 Portland，邮编就要用波特兰对应的邮编段。三者不匹配是"地址无效"报错的最常见原因。

## 注册步骤

1. 浏览器打开 `account.apple.com`，选择创建账号。
2. 国家或地区选择 **United States**。
3. 填写生日、姓名、邮箱、密码。密码不要与其它站点复用。
4. 填写账单地址，按上一步的原则填州、城市、邮编。
5. **付款方式选择 None / 无**。如果看不到这个选项，通常是地址信息不完整或入口不同——

> 经验做法：换一个创建入口，在 iPhone 的 App Store 里退出当前账号后选择"创建新 Apple ID"，在填写完整地址后更容易出现 None 选项。

6. 收邮件验证，完成后账号即可使用。

## 常见报错与处理

**"此 Apple ID 尚未在 App Store 使用过"**

不是错误，而是提示你还没有同意商店条款。用这个账号登录 App Store 时按提示点"检查"并同意即可。

**"地址无效"或反复要求补全信息**

九成是州、城市、邮编、电话区号不匹配。把地址整体换成同一个州的组合，一次填完再提交。

**收不到验证码邮件**

先看垃圾邮件；仍然收不到就换一个邮箱重新注册。少用临时邮箱，这类域名的邮件很容易被丢弃。

**提示需要添加付款方式**

说明当前入口不接受"无"。可以选择带银联或 Visa 标识的卡片先绑定（美区账号也可以用国内发行的部分卡片），或者换个入口按上一节的做法再试一次。

## 登录设备：只登商店，不登 iCloud

拿到账号后，在 iPhone 上这样操作：

1. 「设置 → 顶部 Apple 账户 → 媒体与购买项目」，退出当前账号，登录美区账号；
2. 打开 App Store 搜索并安装需要的客户端；
3. 装完后可以切回自己的主账号。

整个过程**不要退出 iCloud、不要在"设置"最顶部登录这个账号**。App Store 的媒体与购买项目与 iCloud 是两套独立登录，只动前者就能下载应用。

## 安装之后的两件事

**更新应用时需要切回美区账号。** App Store 的更新权限绑定在购买账号上，用主账号登录时只能看到更新提示却点不动，切回美区账号更新完再切回来即可。

**给账号开启双重认证。** 自己注册的账号同样需要保护，尤其是它已经绑定了你的设备。开了双重认证之后，即使密码泄露也不容易被盗用。

如果下载好客户端之后卡在订阅导入环节，排查思路见[小火箭订阅导入失败排查](shadowrocket-subscribe-troubleshooting.html)；手机端从借电脑搭桥到装上客户端的完整路线见 [iPhone 翻墙教程](ios-proxy-setup.html)。
