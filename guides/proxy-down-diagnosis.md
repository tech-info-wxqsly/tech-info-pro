# 机场节点突然用不了：按顺序排查可能原因

先做几分钟自检，再决定是否联系服务商。下面的步骤用于缩小排查范围，不一定能单独确诊；若涉及公司、校园或公共网络，请遵守网络管理规则与使用授权。

## 一、五分钟自检流程

按顺序做，不要跳步：

1. **更新订阅**。服务商可能会调整节点，先排除本地仍在使用旧配置的情况。
2. **检查节点状态**。记录全部还是部分节点异常，这能帮助缩小范围，但不能单独确诊。
3. **切换协议**。Hysteria2 类的换 Vless 类试试，反之亦然。
4. **切换网络**。手机开热点让电脑连上，再试一次。
5. **核对系统时间**。时间偏差会导致 TLS 握手失败，症状和"节点全挂"一模一样。
6. **分别检查官网/后台与节点**。官网能打开只说明该域名当前可访问，不能证明节点链路正常；记录两者的现象，便于继续定位。

## 二、现象对照表

| 现象 | 最可能的原因 | 该做什么 |
| --- | --- | --- |
| 全部节点超时，官网能打开 | 节点侧故障、配置问题或当前网络与节点链路不通等 | 查看服务商公告、客户端日志，并在获准的另一网络下对照 |
| 全部节点超时，官网也打不开 | 本地网络、域名解析、服务商站点或其他连接问题 | 分别测试其他网站与网络，核对官方公告或备用域名 |
| 只有部分节点超时 | 个别节点、线路或配置异常 | 更新订阅、尝试其他节点并记录差异 |
| 能连上但速度极慢 | 节点负载、线路拥塞、本地网络或套餐限制等 | 在相近时段对照节点和网络，查看剩余流量及限速规则 |
| 只有某些 App 打不开 | 可能与分流规则或 App 网络实现有关 | 检查规则和日志；仅在可信环境下临时对照其他模式 |
| 刚连上就断、反复重连 | 网络可达性、节点状态、客户端配置等 | 查看日志，并按服务商说明检查其他传输配置 |

## 三、常见原因展开说

**个别节点不可用。** 可能原因包括节点维护、服务端配置变更、网络路径异常或节点地址不可达等。仅凭客户端测速结果不能确定是 IP 被封锁；先更新订阅、查服务公告，并比较同一网络下其他节点。

**服务商维护或迁移。** 后台公告里通常有说明，表现为全部节点同时不可用、持续几分钟到几小时。

**当前网络与节点不兼容。** 校园网、公司网络、酒店 WiFi 等可能有访问控制或设备隔离；也可能是 DNS、路由、节点或客户端配置问题。若同一设备在另一张网络下表现不同，这能提示问题与网络环境有关，但不能单独确定具体机制；请遵守网络管理规则。

**本机配置问题。** 系统时间不准、端口冲突、旧配置缓存、规则误伤国内域名，都会造出"不能用"的错觉。判断办法：手机在另一张 SIM 卡流量下能否正常使用。

**后台与节点访问结果不同。** 后台打不开但已导入的节点仍能用，说明两条访问路径的表现不同；可能与域名解析、网络策略或服务商维护有关。不要据此断定是域名被拦，先核对官方公告并使用已确认的官方入口。

## 四、网络或服务状态变化时

网络质量、路由、服务端维护、客户端版本与套餐状态都可能变化，表现相似时不要先假定单一原因。可按以下顺序处理：

* 查看服务商公告并更新订阅；
* 在获准使用的网络环境下比较不同节点或配置；
* 保留合规、可用的备选服务方案，并记录变更时间与错误信息。

## 五、什么时候该考虑换服务商

出现下面这些情况，就别再续了：

| 情况 | 说明 |
| --- | --- |
| 连续一周频繁全部失效 | 可用性持续不符合自己的需要，应向服务商核实并重新评估 |
| 客服长期无响应、公告不更新 | 服务稳定性没有保障 |
| 频繁换域名却从不说明原因 | 运营连续性存疑 |
| 实测速度长期低于承诺的零头 | 要么超售严重，要么线路质量本就如此 |

换之前建议先用新服务商的最小档测试几天晚高峰，确认速度满意再迁移，避免从一个坑跳进另一个坑。选购思路见[机场套餐怎么选](plan-choosing-guide.html)。

日常的使用习惯也值得整理一下：订阅链接怎么备份、泄露了怎么处理，见[机场订阅链接怎么获取与备份](subscription-link-guide.html)；客户端侧的排查步骤见[小火箭订阅导入失败排查](shadowrocket-subscribe-troubleshooting.html)。
