# 机场突然用不了：先分清是谁的问题

一句话结论：**先做五分钟自检，再决定要不要找客服。** 大多数"突然不能用了"都能在自检里定性，直接去问客服反而要等更久。

## 一、五分钟自检流程

按顺序做，不要跳步：

1. **更新订阅**。节点列表每天在变，先排除"你用的节点已经被换掉"。
2. **测速全部节点**。看是全部超时还是只有部分，这一步直接决定后面的方向。
3. **切换协议**。Hysteria2 类的换 Vless 类试试，反之亦然。
4. **切换网络**。手机开热点让电脑连上，再试一次。
5. **核对系统时间**。时间偏差会导致 TLS 握手失败，症状和"节点全挂"一模一样。
6. **打开机场官网或后台**。官网能打开，说明你的网络没问题，方向的判断依据就齐了。

## 二、现象对照表

| 现象 | 最可能的原因 | 该做什么 |
| --- | --- | --- |
| 全部节点超时，官网能打开 | 服务商侧故障或整体被针对 | 等公告，同时切到备用线路 |
| 全部节点超时，官网也打不开 | 本地网络拦截，或服务商换域名 | 换网络验证，关注公告 |
| 只有部分节点超时 | 单个节点 IP 被封锁 | 换节点，不必惊慌 |
| 能连上但速度极慢 | 运营商标记限速或晚高峰拥堵 | 换线路或换协议，避开高峰实测 |
| 只有某些 App 打不开 | 分流规则未覆盖 | 临时切全局验证，补规则 |
| 刚连上就断、反复重连 | 当前网络限制 UDP 或节点不稳 | 换 TCP 类协议 |

## 三、常见原因展开说

**节点被封锁。** 这是最日常的情况：某个 IP 被识别后失效，服务商会补新节点。表现为部分节点突然全红，其余正常。

**服务商维护或迁移。** 后台公告里通常有说明，表现为全部节点同时不可用、持续几分钟到几小时。

**本地网络限制。** 校园网、公司网络、部分酒店 WiFi 会限制 UDP 或对特定端口做拦截；运营商的 QoS 则可能只针对 UDP 大流量做限速。这也是为什么同一个订阅在手机上正常、在公司网络上就完全不行。

**本机配置问题。** 系统时间不准、端口冲突、旧配置缓存、规则误伤国内域名，都会造出"不能用"的错觉。判断办法：手机在另一张 SIM 卡流量下能否正常使用。

**面板域名被拦。** 后台打不开但节点能用，属于面板域名被拦截，不影响实际使用，等服务商换域名即可。

## 四、特殊时期要有预期

网络管控收紧的时段，封锁强度和恢复速度都会变差：部分 IP 段被针对、部分协议特征被识别、节点存活时间明显缩短。这时正确的应对不是反复刷新，而是：

* 保留**至少两条不同服务商的线路**，一条主力一条备用；
* 订阅里保留**不同协议的节点**，UDP 被封时切 TCP 类；
* 把自动更新订阅打开，减少"用着旧节点"的时间。

## 五、什么时候该考虑换服务商

出现下面这些情况，就别再续了：

| 情况 | 说明 |
| --- | --- |
| 连续一周频繁全部失效 | 说明线路或技术方案已经跟不上当前封锁强度 |
| 客服长期无响应、公告不更新 | 服务稳定性没有保障 |
| 频繁换域名却从不说明原因 | 运营连续性存疑 |
| 实测速度长期低于承诺的零头 | 要么超售严重，要么线路质量本就如此 |

换之前建议先用新服务商的最小档测试几天晚高峰，确认速度满意再迁移，避免从一个坑跳进另一个坑。选购思路见[机场套餐怎么选](plan-choosing-guide.html)。
